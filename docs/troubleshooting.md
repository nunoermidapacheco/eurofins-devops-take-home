# Troubleshooting

Common problems and where to look first. Most of them come from a missing prerequisite rather than from the scripts themselves.

[← Back to the README](README.md)

## Common problems

| Symptom | Likely cause | What to check |
|---|---|---|
| IIS returns `HTTP 500.19` or `502.5` | .NET Hosting Bundle missing, or application files missing | Install the Hosting Bundle and check that `C:\Eurofins\HelloWorld` contains the published files |
| IIS returns `HTTP 503` | Application pool stopped, often after a wrong identity password | `Get-WebAppPoolState -Name HelloWorldPool`, then `Start-WebAppPool -Name HelloWorldPool` |
| `WebAdministration` module not found | IIS management tools not installed | Enable *IIS Management Scripts and Tools* in Windows Features |
| Script fails with access denied | PowerShell is not elevated | Reopen PowerShell with *Run as Administrator* |
| Browser warns about the HTTPS site | Self-signed certificate | Expected: the certificate is generated by the script and is not from a trusted authority |
| Monitor service fails to start with a logon error | `HelloWorldUser` lacks the *Log on as a service* right | Grant the right in *Local Security Policy* |
| Monitor service starts but `status.log` is missing | No write permission on the monitor folder | Give `HelloWorldUser` write access to `C:\Eurofins\HelloWorldMonitor` |
| Monitor logs code `0` | The site is not running, or nothing is listening on port `8080` | `Get-Website -Name HelloWorld`, then `Start-Website -Name HelloWorld` |
| Monitor stopped and did not come back | Recovery not configured, or the 300 seconds have not passed yet | `sc.exe qfailure HelloWorldMonitor` |
| Docker reports `address already in use` | Something else is using port `9090` | Stop it, or change the host port in the script |
| Docker pull fails | No internet access, or Docker is not running | `docker info` and check the connection |
| IIS returns `HTTP 500.35` on the site root | ASP.NET Core does not allow two apps in the same application pool | Use `/HelloWorld/` in the URL. The site root is not used |

## Where the logs are

| What | Location |
|---|---|
| IIS request logs | `C:\Eurofins\IISLogs` inside a W3SVC subfolder | 
| Monitor status log | `C:\Eurofins\HelloWorldMonitor\status.log` |
| Application errors on IIS | Windows *Event Viewer > Windows Logs > Application* |
| Container output | `docker logs helloworld` |
